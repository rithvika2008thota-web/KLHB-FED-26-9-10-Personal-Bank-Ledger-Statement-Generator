## 📌 Abstract

The **Personal Bank Ledger and Statement Generator** is a user-friendly financial management system designed to simplify the process of recording, monitoring, and analyzing personal banking transactions. Instead of maintaining handwritten records, the system provides a **digital ledger** where deposits, withdrawals, transfers, dates, transaction details, and account balances can be systematically maintained.

The application automatically updates the account balance whenever a transaction is recorded and organizes the information into a **clear and structured bank statement**. Users can easily review their financial activity, track the movement of money, and understand their transaction history without manually calculating every balance.

The primary objective of this project is to **digitize personal financial record management** and reduce the effort involved in manual bookkeeping.
